# 💻 FrontEnd

Repositório destinado ao desenvolvimento de projetos práticos utilizando **HTML5, CSS3, JavaScript e React**, criados durante minha formação em **Análise e Desenvolvimento de Sistemas**.

Os projetos foram desenvolvidos com o objetivo de consolidar conceitos fundamentais de desenvolvimento Front-End, lógica de programação, manipulação do DOM, algoritmos, regras de negócio e construção de interfaces interativas.

Cada pasta representa um projeto independente, abordando diferentes desafios e conceitos da programação web.

---

# 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* React
* Bootstrap 5

---

# 📂 Projetos

## 🪪 Validador de CPF

Sistema responsável por validar números de CPF utilizando o algoritmo oficial de cálculo dos dígitos verificadores.

### Conceitos aplicados

* Manipulação de strings
* Expressões regulares (Regex)
* Estruturas condicionais
* Laços de repetição
* Algoritmos de validação
* Manipulação do DOM

---

## 🛡️ Validador de Segurança

Aplicação que realiza validação de cartões utilizando o **Algoritmo de Luhn**, além de identificar bandeira, setor e banco emissor com base nos prefixos informados.

### Conceitos aplicados

* Algoritmo de Luhn
* Manipulação de strings
* Regras de negócio
* Estruturas condicionais
* Funções reutilizáveis
* Atualização dinâmica da interface

---

## ❌⭕ Jogo da Velha

Implementação do clássico jogo da velha utilizando **React**, explorando componentes e gerenciamento de estado.

### Conceitos aplicados

* React
* Componentização
* Hooks (`useState`)
* Props
* Fluxo de dados
* Renderização reativa
* Lógica de jogos

---

## 🛒 Sistema de Loja

Simulação de um sistema simples de caixa para registro de compras utilizando código de produto e quantidade.

### Conceitos aplicados

* Arrays
* Objetos

* Organização de dados

## 👥 Lista de Convidados

Aplicação para gerenciamento de convidados, permitindo adicionar, editar, concluir e excluir registros.

### Conceitos aplicados

## 💳 Calculadora de Taxas Bancárias

# 📈 Evolução dos Projetos

Os projetos foram desenvolvidos em ordem crescente de complexidade, permitindo consolidar gradualmente os conhecimentos adquiridos durante os estudos.

Ao longo do repositório é possível observar a evolução desde aplicações mais simples, como conversores e calculadoras, até projetos com algoritmos de validação, gerenciamento de listas, simulação de sistemas comerciais e desenvolvimento utilizando React.

Essa progressão demonstra a aplicação contínua de novos conceitos e boas práticas de programação, refletindo meu processo de aprendizado na área de desenvolvimento Front-End.
