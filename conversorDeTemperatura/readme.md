# 🌡️ Conversor de Temperatura

Projeto desenvolvido com HTML, CSS e JavaScript para realizar conversão de temperaturas entre as escalas Celsius (°C) e Fahrenheit (°F) em tempo real.

## 📌 Objetivo

Praticar conceitos fundamentais de desenvolvimento Front-End, incluindo manipulação do DOM, captura de eventos, validação de entrada e aplicação de fórmulas matemáticas utilizando JavaScript.

---

## 🚀 Funcionalidades

* Conversão de Celsius → Fahrenheit
* Conversão de Fahrenheit → Celsius
* Atualização automática durante a digitação
* Validação de campos vazios
* Exibição do resultado com duas casas decimais
* Interface simples e responsiva

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6)

---

## 📚 Conceitos praticados

### HTML

* Estruturação semântica da página
* Uso de formulários e campos numéricos

### CSS

* Centralização com Flexbox
* Estilização de formulários
* Organização visual e experiência do usuário

### JavaScript

* Seleção de elementos com `getElementById()`
* Manipulação de eventos com `addEventListener()`
* Conversão de tipos usando `parseFloat()`
* Tratamento de valores inválidos com `isNaN()`
* Atualização dinâmica da interface
