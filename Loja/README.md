# 🛒 Sistema de Caixa / Loja

Projeto desenvolvido com HTML, Bootstrap e JavaScript simulando um sistema simples de caixa para registro de compras.

A aplicação permite inserir produtos por código, definir quantidade e montar dinamicamente uma lista de itens adicionados ao carrinho.

---

## 📌 Objetivo

Praticar conceitos de desenvolvimento Front-End aplicados a um cenário próximo de sistemas comerciais, utilizando manipulação de DOM, estruturas de dados e atualização dinâmica da interface.

---

## 🚀 Funcionalidades

* Cadastro e busca de produtos por código
* Inserção de quantidade
* Adição de itens ao carrinho
* Cálculo de subtotal por produto
* Atualização dinâmica da lista de compras
* Reprodução de áudio ao registrar item
* Interface construída com Bootstrap

---

## 🧩 Funcionamento

1. Informar o código do produto.
2. Definir quantidade desejada.
3. Adicionar item ao carrinho.
4. O sistema calcula automaticamente o subtotal.
5. Os produtos aparecem na lista de compras.
