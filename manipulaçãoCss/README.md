# 🎨 Página Web Responsiva com HTML e CSS

Projeto desenvolvido com HTML5 e CSS3 para criar uma página informativa sobre a história da Ciência da Computação, utilizando diversos elementos semânticos da web e técnicas de estilização responsiva.

A aplicação reúne conteúdos organizados em seções, navegação interna, tabelas, formulários e componentes visuais, servindo como exercício de estruturação de páginas e aplicação de estilos modernos.

---

## 📌 Objetivo

Praticar o desenvolvimento de páginas web utilizando HTML semântico e CSS, explorando organização de conteúdo, responsividade, estilização de componentes e experiência do usuário.

---

## 🚀 Funcionalidades

* Navegação por âncoras entre seções da página
* Layout centralizado e responsivo
* Organização do conteúdo utilizando HTML semântico
* Exibição de tabelas com estilização personalizada
* Formulário para envio de informações
* Área de curiosidades utilizando elementos auxiliares
* Efeitos visuais em menus e botões
* Rolagem suave entre as seções da página

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3

---

## 📚 Conceitos praticados

### HTML

* Estruturação semântica da página
* Utilização de `header`, `nav`, `section`, `article`, `aside` e `footer`
* Listas ordenadas e não ordenadas
* Tabelas
* Formulários
* Elementos `details` e `summary`
* Citações utilizando `blockquote`
* Elementos `pre` e `address`

### CSS

* Reset de estilos
* Box Model
* Flexbox
* Pseudo-classes (`:hover`)
* Seletores por elemento, classe e ID
* Estilização de formulários
* Responsividade
* Transições
* Sombras (`box-shadow`)
* Bordas arredondadas (`border-radius`)
* Rolagem suave (`scroll-behavior`)

---

## 🧩 Estrutura da página

A aplicação está organizada em diferentes áreas de conteúdo:

* **Cabeçalho** com título e descrição
* **Menu de navegação** com links internos
* **Seção sobre pioneiros da computação**
* **Histórias e curiosidades sobre bugs**
* **Curiosidades da Internet**
* **Linguagens de programação**
* **Linha do tempo da computação**
* **Formulário para envio de curiosidades**
* **Rodapé com informações de contato**

Este projeto foi desenvolvido para consolidar conhecimentos em HTML5 e CSS3 por meio da construção de uma página completa, utilizando elementos semânticos e boas práticas de organização visual.
