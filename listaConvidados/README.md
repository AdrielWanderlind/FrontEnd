# 👥 Lista de Convidados VIP

Projeto desenvolvido com HTML, CSS e JavaScript para gerenciamento de uma lista de convidados de forma dinâmica.

A aplicação permite adicionar, editar, marcar e remover convidados diretamente pela interface, simulando operações comuns de gerenciamento de dados no Front-End.

---

## 📌 Objetivo

Praticar conceitos de desenvolvimento Front-End por meio da construção de uma aplicação interativa utilizando manipulação do DOM, eventos e atualização dinâmica da interface.

---

## 🚀 Funcionalidades

* Adicionar convidados
* Editar nomes existentes
* Marcar convidados como concluídos
* Excluir convidados da lista
* Atualização automática da interface
* Validação para impedir entradas vazias

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6)

---

## 📚 Conceitos praticados

### HTML

* Estruturação de formulários
* Organização de listas dinâmicas
* Uso de elementos interativos

### CSS

* Layout centralizado
* Estilização de componentes

### JavaScript

* Manipulação do DOM
* Eventos com `addEventListener()`

* Estruturas condicionais

---

## 🧠 Funcionalidades implementadas

### Adicionar convidado

Permite incluir novos nomes na lista.

### Concluir

Marca visualmente o convidado utilizando alteração de classe CSS.

### Editar

Permite alterar informações já cadastradas.

### Excluir

Remove convidados dinamicamente da lista.
